# Tile Converter

Use `python bitmap_2_assembly.py` to convert a tile set bitmap file to assembly code

## Limits

- Use only the colors in `bitmap_2_assembly.py` in your bitmap file **or** adjust the colors in the code to your used colors
- will crash if the bitmap file is not a multitude of 4x8 pixels
- will crash if one tile uses more than 2 colors and 2 shared colors
